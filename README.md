# Lifestyle & Sleep Statistical Analysis

## Overview

This project analyzes the relationship between sleep and lifestyle factors using survey data collected from 60 respondents.

The analysis was completed as part of a statistical methods project and focused on identifying relationships between sleep duration and factors such as stress, technology use, caffeine consumption, exercise, and relaxation.

## Data Collection

* **23-question survey**
* **60 responses**
* Data organized and analyzed using Microsoft Excel
* Variables included sleep duration, stress, technology use, caffeine consumption, exercise, and relaxation

## Analysis

The project included:

* Descriptive statistics
* Probability distributions
* Correlation analysis
* Regression analysis
* Pivot tables
* Histograms
* Bar charts
* Scatter plots

## Key Findings

* The average reported sleep duration was **6.52 hours**.
* The average reported technology use before sleep was **81.92 minutes**.
* The relationship between stress and sleep duration was weakly negative (**r = -0.231**).
* Caffeine intake explained approximately **0.13%** of the variation in sleep duration (**R² = 0.0013**).
* Overall, the analysis did not identify a single lifestyle factor that strongly predicted sleep duration.

## Limitations

The project was based on a relatively small survey sample of 60 respondents. Survey design and wording may also have affected the results.
